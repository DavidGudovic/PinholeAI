# Pinhole

A simple, private, offline AI image generator. Pick a model, type a prompt, press Generate.

- Auto-wires every model (VAE, text encoders, best settings) — no node graphs, no jargon.
- One-click download of the best model for your GPU; every model shows how much VRAM it needs.
- Built-in CivitAI browser with plain-language filters.
- Create (txt2img), Edit ("make it evening", "replace the mug with a bottle"), Describe (img2text), reusable Styles.
- Your prompts and images stay on your computer. No telemetry. Works offline once models are downloaded.
- Windows and Ubuntu. Powered by [stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp) and [llama.cpp](https://github.com/ggml-org/llama.cpp).

**Status:** design phase. See [`docs/SPEC.md`](docs/SPEC.md).
