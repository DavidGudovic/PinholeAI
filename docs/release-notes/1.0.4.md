Pinhole 1.0.4 lets you drop pictures in the same way you paste them, and makes reference pictures easier to use: a filter for models that take one, and a shape that follows the picture. If you have 1.0.3 on Windows or as the AppImage, Settings → Check for updates installs 1.0.4 for you. With the `.deb`, download 1.0.4 below and install it once with `sudo apt install ./Pinhole-1.0.4-linux-amd64.deb`; from then on, Check for updates installs new versions for you after asking for your password. Your `Data` folder is kept.

## What's new

- **Drop a picture anywhere.** Drop a picture on the window and Pinhole asks what it's for, as with paste: a reference in Create, a picture to change in Edit, or Describe. A picture dragged straight out of a web browser works when the browser hands over the picture itself; otherwise Pinhole asks you to right-click it, choose Copy image and paste it. Links are never downloaded.
- **Paste from Chrome on Linux.** Right-click → Copy image in Chrome, then Ctrl+V in Pinhole now opens the paste chooser.
- **Reference picture models.** Models → Browse has a **Reference picture** tag that shows only models that can follow a reference picture in Create, and those models carry a badge.
- **Same as reference.** With a reference picture set, Create makes the picture in the reference's shape. It's picked for you; choose another shape to turn it off. Width and Height in Fine-tune still win.
- **Same character keeps your model.** More like this → Same character stays in Create with the picked model whenever it can follow a reference picture, also for pictures added from your computer.
- **The `.deb` updates itself.** From 1.0.4 on, Check for updates on the `.deb` shows **Update and restart**. Ubuntu asks for your password, then the new version is installed and opened.

## Download

| System | File |
|---|---|
| Windows 10/11 (x64), installer | `Pinhole-1.0.4-windows-x64-setup.exe` |
| Windows 10/11 (x64), portable | `Pinhole-1.0.4-windows-x64-portable.zip` (unzip, run `Pinhole\Pinhole.exe`; data stays in `Data\`) |
| Linux x86_64 | `Pinhole-1.0.4-linux-x86_64.AppImage` or `Pinhole-1.0.4-linux-amd64.deb` |

- Windows may warn that the app is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**. Windows 10 needs the Microsoft Edge WebView2 Runtime (the installer adds it if missing).
- Image generation on Linux needs Ubuntu 24.04 or newer (glibc 2.38+).
- No models or engine are bundled. Pinhole downloads the engine for your GPU and the models you pick, once, and checks every download's SHA-256.
- To verify your download, run `sha256sum -c SHA256SUMS.txt` (or `Get-FileHash` on Windows).
- **Updates:** Settings → Check for updates installs new versions for you. On the `.deb` it asks for your password first; a copy built from source opens this page instead. Each release includes `SHA256SUMS.txt.sig`, the maintainer's signature of `SHA256SUMS.txt`, and Pinhole only installs updates that carry a valid signature.
