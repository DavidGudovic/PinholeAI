Pinhole 1.0.4 makes it quicker to go from a first picture to a finished one: **Close to this one**, **Finish at Best quality**, the same prompt **on another model**, choices in braces, and one edit applied to several pictures. Saved pictures now go to your Pictures folder, and pictures can be dropped in like they're pasted. If you have 1.0.3 on Windows or as the AppImage, Settings → Check for updates installs 1.0.4 for you. With the `.deb`, download 1.0.4 below and install it once with `sudo apt install ./Pinhole-1.0.4-linux-amd64.deb`; from then on, Check for updates installs new versions for you after asking for your password. Your `Data` folder is kept.

## What's new

- **Close to this one.** More like this → **Close to this one** makes new pictures that keep the selected picture's layout and change only the details. Variations still gives new layouts.
- **Finish at Best quality.** For a picture made at Fast or Balanced, Upscale → **Finish at Best quality** makes it again at Best with the same seed, so the draft you liked becomes the final.
- **On another model.** More like this → **On another model…** makes the same prompt, seed and shape on another installed model and shows both pictures side by side, each labelled with its model.
- **Choices in braces.** Write `a {red|blue|green} car` and one Generate makes one picture per choice, with the same seed so only the choice changes. Several groups combine, up to 16 pictures.
- **Apply one edit to several pictures.** In Edit, **Also apply to…** picks more pictures from this session or from files. The same change or restyle then runs on each of them, one after the other.
- **Save as one sheet.** Save → **Save as one sheet** saves the pictures of one run as a single grid picture.
- **Saves go to your Pictures folder.** Save now writes to `Pictures/Pinhole`. Settings → Saved pictures shows the folder and lets you change it. Pictures saved before stay where they were. The portable Windows copy keeps saving into its `Data` folder.
- **Repeats without seams.** With an SD 1.5 or SDXL model, Fine-tune → **Repeats without seams** makes patterns and textures whose edges join up when repeated, and **Show tiled** previews it 2×2. The model reloads the first time you make a picture after turning it on or off.
- **One setup card.** If you skipped setup, Create shows one card listing what's still missing (image engine, safety check, a model) with one button to get it all.
- **Drop a picture anywhere.** Drop a picture on the window and Pinhole asks what it's for, as with paste: a reference in Create, a picture to change in Edit, or Describe. A picture dragged straight out of a web browser works when the browser hands over the picture itself; otherwise Pinhole asks you to right-click it, choose Copy image and paste it. Links are never downloaded.
- **Paste from Chrome on Linux.** Right-click → Copy image in Chrome, then Ctrl+V in Pinhole now opens the paste chooser.
- **Pictures from this session.** Wherever a picture is asked for (Edit, Another image, Add another image, Describe and the reference picture), the pictures you made this session are offered next to choosing a file.
- **Reference picture models.** Models → Browse has a **Reference picture** switch that shows only models that can follow a reference picture in Create, and those models carry a badge.
- **Same as reference.** With a reference picture set, Create makes the picture in the reference's shape. It's picked for you; choose another shape to turn it off. Width and Height in Fine-tune still win.
- **Same character keeps your model.** More like this → Same character stays in Create with the picked model whenever it can follow a reference picture, also for pictures added from your computer.
- **The `.deb` updates itself.** From 1.0.4 on, Check for updates on the `.deb` shows **Update and restart**. Ubuntu asks for your password, then the new version is installed and opened.
- **Edit model hint.** When Edit opens in Restyle only because no edit model is installed, one line offers the edit model, which changes one thing and keeps the rest.
- **Tidier model browser.** Models → Browse keeps the main filters in view and folds Tags, Price, Commercial use and Hide anime under **More filters**.
- **Safe mode in Installed.** Example pictures opened from Models → Installed follow Safe mode the same way Browse does, and with Safe mode on, Browse leaves out the tags that need it off.
- **Fixes.** The Landscape shape no longer gets cut off in narrow windows. Turning Safe mode on in Settings now also turns it on in an open Models → Browse. Links in a model creator's description are no longer looked up by Windows before you click them. On Windows, crash reports from the app window now stay on your computer.

## Download

| System | File |
|---|---|
| Windows 10/11 (x64), installer | `Pinhole-1.0.4-windows-x64-setup.exe` |
| Windows 10/11 (x64), portable | `Pinhole-1.0.4-windows-x64-portable.zip` (unzip, run `Pinhole\Pinhole.exe`; data stays in `Data\`) |
| Linux x86_64 | `Pinhole-1.0.4-linux-x86_64.AppImage` or `Pinhole-1.0.4-linux-amd64.deb` |

- Windows may warn that the app is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**. Windows 10 needs the Microsoft Edge WebView2 Runtime (the installer adds it if missing).
- Image generation on Linux needs Ubuntu 24.04 or newer (glibc 2.38+).
- No models or engine are bundled. Pinhole downloads the engine for your GPU and the models you pick, once, and checks every download's SHA-256.
- To verify your download, run `sha256sum -c SHA256SUMS.txt` (or `Get-FileHash` on Windows).
- **Updates:** Settings → Check for updates installs new versions for you. On the `.deb` it asks for your password first; a copy built from source opens this page instead. Each release includes `SHA256SUMS.txt.sig`, the maintainer's signature of `SHA256SUMS.txt`, and Pinhole only installs updates that carry a valid signature.
