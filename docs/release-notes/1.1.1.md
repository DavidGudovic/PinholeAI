Pinhole 1.1.1 is a bug fix release: smoother model downloads, an Edit brush that matches what the edit does, and a round of small fixes across the app. Settings → Check for updates installs 1.1.1 for you; the `.deb` asks for your password first. With the `.deb` 1.0.3 or older, download 1.1.1 below and install it once with `sudo apt install ./Pinhole-1.1.1-linux-amd64.deb`. Your `Data` folder is kept.

## Fixes

- **Resuming a download on a nearly full disk.** A cancelled model download can be resumed when only the rest of the file fits, since the part already downloaded is kept.
- **Faster start for model downloads.** A different file already at the download's destination is no longer read in full before the download starts.
- **The model stays loaded more often.** When a request stops before a picture is made, the loaded model stays loaded, so the next picture starts sooner.
- **Deleting a model while another one loads** finishes right away instead of waiting for the load.
- **Edit brush.** The painted spot is hidden while "Only change here" is off and comes back when you turn it on. Erasing all of it switches back to Add detail. Try again works after several Fix details edits in a row.
- **Size badges stay current.** "Fits / Tight / Too big" in Create and Edit update once your graphics card is detected or its settings change.
- **Model list.** A deleted model no longer reappears when two refreshes overlap.
- **Add a file** checks that it can save the models list before copying a large file, and removes the copy if adding it fails.
- **Upscale** picks a model whose file is still there.
- **Add-on weights** can be cleared and typed again.
- **Downloads in Describe and Improve** say why they failed and offer Try again. The Install dialog offers Try again when it can't load.
- **"This model still needs…"** in Create has a Get missing parts button.
- **Keyboard.** Tab stays inside dialogs, side panels and the full-screen viewer. Enter saves in Save as style.
- **Looks.** The full-screen viewer buttons are readable in the light theme, the result buttons wrap neatly in narrower windows, the Edit toolbar buttons are one size, and disabled menu items and the disabled Improve button no longer light up on hover; Improve shows why it is off.
- **Engine messages** keep accented and other non-English characters intact.

## Download

| System | File |
|---|---|
| Windows 10/11 (x64), installer | `Pinhole-1.1.1-windows-x64-setup.exe` |
| Windows 10/11 (x64), portable | `Pinhole-1.1.1-windows-x64-portable.zip` (unzip, run `Pinhole\Pinhole.exe`; data stays in `Data\`) |
| Linux x86_64 | `Pinhole-1.1.1-linux-x86_64.AppImage` or `Pinhole-1.1.1-linux-amd64.deb` |

- Windows may warn that the app is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**. Windows 10 needs the Microsoft Edge WebView2 Runtime (the installer adds it if missing).
- Image generation on Linux needs Ubuntu 24.04 or newer (glibc 2.38+).
- No models or engine are bundled. Pinhole downloads the engine for your GPU and the models you pick, once, and checks every download's SHA-256.
- To verify your download, run `sha256sum -c SHA256SUMS.txt` (or `Get-FileHash` on Windows).
- **Updates:** Settings → Check for updates installs new versions for you. On the `.deb` it asks for your password first; a copy built from source opens this page instead. Each release includes `SHA256SUMS.txt.sig`, the maintainer's signature of `SHA256SUMS.txt`, and Pinhole only installs updates that carry a valid signature.
