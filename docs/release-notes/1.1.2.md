Pinhole 1.1.2 is a bug fix release: less memory use during long sessions and queued pictures, clearer block messages, and a round of fixes across the app. Settings → Check for updates installs 1.1.2 for you; the `.deb` asks for your password first. With the `.deb` 1.0.3 or older, download 1.1.2 below and install it once with `sudo apt install ./Pinhole-1.1.2-linux-amd64.deb`. Your `Data` folder is kept.

## Memory

- **Graphics memory during a queue.** An idle Describe/Improve engine is closed before each picture and each upscale, so it no longer holds graphics memory the picture needs.
- **16 GB cards** get the memory settings meant for 16 GB cards. They report slightly less than 16 GB and were treated like 12 GB cards.
- **After running out of memory**, the "more room" choice is remembered for the model only when the retried picture succeeded, and the engine note shows it right away.
- **Add-ons** are applied during each step instead of being merged into the model's weights, so weights kept in system memory stay backed by the model file instead of filling RAM and swap.
- **The 5-minute unload** also covers an engine that was only used for Upscale, or for a picture that failed after it was sent.
- **Save as one sheet** handles one picture at a time, using much less memory with large pictures. Loading the picture check and checking large pictures uses less memory too.
- **Thumbnails** in the results strip, Edit history and picture pickers use small copies instead of full-size pictures.

## Speed

- **Linked folders.** Duplicate model files are no longer read in full on every rescan, and add-ons from linked folders are prepared without holding up the rest of the app.
- **Auto upscale** reuses what the check already measured instead of measuring the picture again.
- **Edit** re-renders less while you type, and the eraser reads back only the painted area. "Also apply to…" imports two pictures at a time.

## Fixes

- **Block messages** read "Pinhole cannot help with this." with a short reason, and say that automated checks can make mistakes.
- **The unsaved-pictures dialog** says in red what Reset, closing Pinhole or loading another picture into Edit deletes.
- **"Can't reach your NVIDIA card"** no longer shows when the model runs on the card in parts.
- **Save all** before Close or Reset also saves pictures that finish while the folder picker is open.
- **Keep this look** follows the next picture when the selected one is removed.
- **Cancel** before the engine starts keeps the loaded model loaded.
- **Adding a model again** whose file was deleted by hand uses the new copy.
- **If Pinhole can't start**, it shows a message with the error and the Data folder instead of closing silently.
- **After a `.deb` update**, pressing Update again asks for a restart instead of downloading and installing again.
- **Downloads** that drop several times keep going as long as each try makes progress. Old engine versions and leftover engine files are removed at startup.
- **Edit.** Dropping a picture while an edit runs says to wait. Ctrl/Cmd+Enter does nothing while Apply is off. The final prompt preview updates when the picture or the Fix details / Extend choice changes.
- **Paste dialog** only says "Filled in from your clipboard" when it was.

## Download

| System | File |
|---|---|
| Windows 10/11 (x64), installer | `Pinhole-1.1.2-windows-x64-setup.exe` |
| Windows 10/11 (x64), portable | `Pinhole-1.1.2-windows-x64-portable.zip` (unzip, run `Pinhole\Pinhole.exe`; data stays in `Data\`) |
| Linux x86_64 | `Pinhole-1.1.2-linux-x86_64.AppImage` or `Pinhole-1.1.2-linux-amd64.deb` |

- Windows may warn that the app is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**. Windows 10 needs the Microsoft Edge WebView2 Runtime (the installer adds it if missing).
- Image generation on Linux needs Ubuntu 24.04 or newer (glibc 2.38+).
- No models or engine are bundled. Pinhole downloads the engine for your GPU and the models you pick, once, and checks every download's SHA-256.
- To verify your download, run `sha256sum -c SHA256SUMS.txt` (or `Get-FileHash` on Windows).
- **Updates:** Settings → Check for updates installs new versions for you. On the `.deb` it asks for your password first; a copy built from source opens this page instead. Each release includes `SHA256SUMS.txt.sig`, the maintainer's signature of `SHA256SUMS.txt`, and Pinhole only installs updates that carry a valid signature.
