Pinhole 1.0.3 adds picture paste, Add detail for faces, a better upscaler pick, a Side by side view, and Improve for edits. It also tidies the result buttons and lets Upscale wait in the queue. If you have 1.0.2, Settings → Check for updates installs 1.0.3 for you. Your `Data` folder is kept.

## What's new

- **Paste a picture.** Press Ctrl+V with a picture on the clipboard and Pinhole asks what it's for: a reference in Create, or a picture to change in Edit. This also works on Linux.
- **Add detail for faces.** In Edit → Fix details, leave the picture unpainted and press **Add detail**. Pinhole finds the small faces and redraws each one at full detail, one after the other. On photos the faces stay photographic. Progress shows which face it's on ("Face 1 of 2").
- **The upscaler fits the picture.** Upscale picks a photo upscaler for photos and a drawing upscaler for drawings and anime. Edit → Fine-tune → Upscaler lets you choose one yourself, including a skin-texture option for portraits. Each upscaler downloads once, the first time it's used.
- **Side by side.** Compare the reference picture and the result next to each other, in Create and in Edit.
- **Improve keeps what you meant.** Improve rewords your idea where that helps the model and adds details, while keeping what you asked for. It now also works for **Describe a change** in Edit.
- **Tidier result buttons.** Under a result: **Save** (with Save as and Save all unsaved), **Edit this**, **More like this** (Variations, Same character), **Upscale** and **Describe**.
- **Upscale waits its turn.** Pressing Upscale while a picture is being made adds it to the queue instead of being blocked.
- **Fixes.** Cancel now works while Upscale is choosing its upscaler, and the Fine-tune prompt preview shows the prompt Add detail really uses.

## Download

| System | File |
|---|---|
| Windows 10/11 (x64), installer | `Pinhole-1.0.3-windows-x64-setup.exe` |
| Windows 10/11 (x64), portable | `Pinhole-1.0.3-windows-x64-portable.zip` (unzip, run `Pinhole\Pinhole.exe`; data stays in `Data\`) |
| Linux x86_64 | `Pinhole-1.0.3-linux-x86_64.AppImage` or `Pinhole-1.0.3-linux-amd64.deb` |

- Windows may warn that the app is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**. Windows 10 needs the Microsoft Edge WebView2 Runtime (the installer adds it if missing).
- Image generation on Linux needs Ubuntu 24.04 or newer (glibc 2.38+).
- No models or engine are bundled. Pinhole downloads the engine for your GPU and the models you pick, once, and checks every download's SHA-256.
- To verify your download, run `sha256sum -c SHA256SUMS.txt` (or `Get-FileHash` on Windows).
- **Updates:** Settings → Check for updates installs new versions for you (the `.deb` package opens this page instead). Each release includes `SHA256SUMS.txt.sig`, the maintainer's signature of `SHA256SUMS.txt`.
