Pinhole 1.1.0 brings together everything from the 1.0 releases with a round of fixes and speed-ups: a faster model browser, clearer messages when a picture is blocked, fewer adults blocked by the age check, and steadier Improve my prompt. Settings → Check for updates installs 1.1.0 for you; the `.deb` 1.0.4 asks for your password first. With the `.deb` 1.0.3 or older, download 1.1.0 below and install it once with `sudo apt install ./Pinhole-1.1.0-linux-amd64.deb`. Your `Data` folder is kept.

## What's new

- **Faster model browser.** Models → Browse keeps only the rows on screen in the page, so scrolling, filtering and going back are quicker, and a model's page loads the pictures you can see first.
- **Why a picture was blocked.** When a picture is blocked, the message now says which check stopped it, in one or two sentences.
- **Fewer adults blocked.** Fewer adults are blocked by the age check.
- **Improve in Edit stays on your change.** A reworded change is used only when it names nothing your instruction doesn't, so "add a red umbrella" can't turn into "add a red umbrella and a hat". Your own words lead otherwise, with the details after them.
- **Improve adds no hair or clothes to scenes without people.** For an idea without a person, Improve leaves out added words about hair or clothes.
- **Repeats without seams is kept in saved settings.** Pictures saved with "Settings (no prompt)" now record it, and reusing their settings turns it back on.
- **Fixes.** Copies of the same model file that are the same size show once in the Size choice.

## Download

| System | File |
|---|---|
| Windows 10/11 (x64), installer | `Pinhole-1.1.0-windows-x64-setup.exe` |
| Windows 10/11 (x64), portable | `Pinhole-1.1.0-windows-x64-portable.zip` (unzip, run `Pinhole\Pinhole.exe`; data stays in `Data\`) |
| Linux x86_64 | `Pinhole-1.1.0-linux-x86_64.AppImage` or `Pinhole-1.1.0-linux-amd64.deb` |

- Windows may warn that the app is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**. Windows 10 needs the Microsoft Edge WebView2 Runtime (the installer adds it if missing).
- Image generation on Linux needs Ubuntu 24.04 or newer (glibc 2.38+).
- No models or engine are bundled. Pinhole downloads the engine for your GPU and the models you pick, once, and checks every download's SHA-256.
- To verify your download, run `sha256sum -c SHA256SUMS.txt` (or `Get-FileHash` on Windows).
- **Updates:** Settings → Check for updates installs new versions for you. On the `.deb` it asks for your password first; a copy built from source opens this page instead. Each release includes `SHA256SUMS.txt.sig`, the maintainer's signature of `SHA256SUMS.txt`, and Pinhole only installs updates that carry a valid signature.
