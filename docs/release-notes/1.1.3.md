Pinhole 1.1.3 makes Pinhole easier to use from the keyboard. Settings → Check for updates installs 1.1.3 for you; the `.deb` asks for your password first. With the `.deb` 1.0.3 or older, download 1.1.3 below and install it once with `sudo apt install ./Pinhole-1.1.3-linux-amd64.deb`. Your `Data` folder is kept.

## Keyboard

- **Closing with unsaved pictures.** The dialog focuses "Close without saving", so Enter closes Pinhole and Escape goes back. Reset and loading another picture into Edit work the same way.
- **The cursor goes back to the prompt** after you pick a model, style, preset, reference picture, image 2 or add-on, so you can keep typing.
- **Opening Create or Edit** from another tab, a result's menu or Describe's "Use as prompt", clicking a section, Reset and starting Pinhole put the cursor in that tab's text field.
- **Menus** move with the Up and Down arrows (Home and End jump to the ends). Left and Right move between Create, Edit, Describe and Models when a section button has focus.
- **Delete, Safe mode, model licence and models-folder dialogs** focus Cancel.
